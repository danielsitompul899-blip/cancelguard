# 🛡️ CancelGuard 

> **Kelola dan batalkan langganan secara transparan langsung dari browser Anda.**

Aplikasi utilitas web ringan untuk mendeteksi, mencatat, dan menyediakan akses cepat ke halaman pembatalan resmi penyedia layanan (seperti Netflix, Spotify, dll.), tanpa memungut data sensitif pengguna.

🌐 **Coba Aplikasi Live di sini:** (https://danielsitompul899-blip.giyhub.io/cancelguard)

---

## ✨ Fitur yang Sudah Berjalan

*   ➕ **Tambah Langganan:** Memasukkan nama platform langganan secara manual.
*   🔗 **Smart Deep-Linking:** Otomatis mencocokkan nama layanan populer (Netflix, Spotify, YouTube) dengan URL pembatalan akun resmi mereka.
*   💾 **Auto-Save (Local Storage):** Data tersimpan aman di memori browser perangkat pengguna. Daftar tidak akan hilang meskipun halaman web di-refresh atau ditutup.
*   🔒 **100% Privacy-First:** Tidak meminta password, email, data kartu kredit, atau akses akun perbankan.

---

## 🛠️ Pembuatan

Aplikasi ini dibangun menggunakan arsitektur web statis yang sangat ringan:
*   **HTML5** - Sebagai struktur dasar halaman web.
*   **CSS3** - Untuk penataan gaya dan tampilan.
*   **JavaScript** - Menangani logika penyimpanan lokal (`localStorage`) dan pembuatan tautan dinamis secara *client-side*.
*   **Deployment** - Di-host secara gratis menggunakan **GitHub Pages**.
